# Foto Bounce

Nostaljik bir platform oyunu. Fotoğrafını yükle, topa dönüştür, halkaları topla ve çıkışa ulaş.

## Kontroller
- Sol / sağ ok veya A / D: hareket
- Yukarı ok, W veya boşluk: zıpla
- P / Escape: duraklat ve devam et
- Mobilde ekrandaki yön ve zıplama tuşlarını kullan.

Üç bölüm, bölüm başına üç can, fotoğrafı yakınlaştırma ve konumlandırma içerir. Kaybedilen can sonrası toplanan halkalar korunur; bölüm yeniden başlatıldığında sıfırlanır.

## Fotoğraflar
Fotoğraflar yalnızca tarayıcı belleğinde işlenir ve hiçbir sunucuya gönderilmez. Sayfa yenilendiğinde silinir. JPG, PNG, WebP ve AVIF desteklenir (en fazla 15 MB). Harici Google Fonts bağlantısı yalnızca yazı tipleri içindir.

## Çalıştırma
`index.html` dosyasını tarayıcıda aç. Derleme ya da paket kurulumu gerektirmez.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Nokia veya orijinal Bounce oyunu ile bağlantılı değildir. Görseller ve seviye tasarımları bu proje için hazırlanmıştır.
